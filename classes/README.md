# Classes

Un fichier Markdown par classe sert de mémoire pédagogique longue durée.

Exemple : `2nde_A.md`.

Chaque fichier peut contenir :
- niveau attendu ;
- exigences de rédaction ;
- tolérances ;
- erreurs récurrentes ;
- remarques issues des corrections précédentes ;
- adaptations de barème propres à la classe.

Les remarques doivent être datées lorsqu'elles proviennent d'un retour sur une correction réelle.
