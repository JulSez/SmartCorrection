# Configurations

Ce dossier contient les paramètres variables du moteur sans dupliquer le code Python.

Exemples de paramètres :
- note individuelle maximale ;
- poids ou plafond de la note de groupe ;
- mode de calcul du groupe ;
- arrondi ;
- bonus ;
- cas particuliers.

Le moteur Python doit interpréter ces paramètres de manière générique.
