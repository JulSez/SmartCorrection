# Savoir-faire

Ce dossier contient les références pédagogiques utilisées pour construire les grilles et guider les corrections.

Les documents doivent décrire les méthodes attendues, les étapes de rédaction et les critères importants.

Ils peuvent être organisés par chapitre ou thème, par exemple :
- `equations.md`
- `fonctions.md`
- `vecteurs.md`

Les savoir-faire servent de référence ; les exigences spécifiques d'une classe restent dans `classes/`.
